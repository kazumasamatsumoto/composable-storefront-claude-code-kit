# コストの集計

## いつ実行するか
- 依頼を 1 件終えて、人に報告する直前に毎回実行する。
- 担当(サブエージェント)は、自分の作業を終えて報告を返す直前に実行する。

## 1. 実行する
リポジトリの最上位で、次のコマンドを実行します。Mac / Linux / Windows(PowerShell)で同じコマンドが使えます。

```
node .claude/skills/cs-cost/scripts/cost.mjs --label "<依頼を 20 字ほどで。例: 送料無料バッジの追加>"
```

- 担当として実行するときは、ラベルの頭に担当名を付ける(例: `"cs-frontend: 送料無料バッジ"`)。
- 試しに見るだけで記録したくないときは、`--no-log` を付ける。

## 2. 報告に付ける
スクリプトが出した表を、そのまま報告の最後に付ける。表には次の行がある。
- **今回の依頼**: 前回の記録からの増分。依頼 1 件の量で、見積もりの実績にはこの行を使う。
- **会話の累計**: 会話の初めからの合計。担当の分も含む。

## 3. 記録
- 実行のたびに `docs/cost-log.csv` に 1 行足す。列は、日時、会話 ID、依頼、累計の数、累計の金額、今回の金額。Excel で開ける。
- 見積もりのときは、この CSV の「今回USD」と「依頼」の列を、機能の大きさごとに並べて使う。

## 数え方(根拠)
- 会話の記録は `~/.claude/projects/<作業フォルダ>/<会話 ID>.jsonl` にある。担当の記録は `<会話 ID>/subagents/agent-*.jsonl` にある。スクリプトは両方を読むだけで、書き換えない。
- 同じ応答が複数行に分かれて書かれていても、応答 ID ごとに 1 回だけ数える。
- 単価は `rates.json` を使う。公式の料金表(https://platform.claude.com/docs/en/about-claude/pricing)を `checked` の日付で写したもの。料金が変わったら、この表を直す。
- 金額は API 料金に換算したもの。Pro / Max などの定額プランでは、この金額を請求されるわけではない(使った量の目安になる)。
- 対象は、いちばん新しい記録(いま書き込まれている会話)。別の会話を数えるときは `--session <会話 ID>` を付ける。

## 気をつけること
- 担当がまだ動いている最中に実行すると、その担当の分は途中までしか入らない。
- 単価表に無いモデルは金額に入らず、表の下に名前が出る。その場合は `rates.json` に足す。
- `docs/cost-log.csv` を共有したくない案件では、`.gitignore` に足す。
