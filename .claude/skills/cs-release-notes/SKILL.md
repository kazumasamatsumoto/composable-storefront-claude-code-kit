# リリースノート

コミット履歴は `git log` で読む。Bash を持たないエージェント(cs-pdm)が使うときは、人か cs-operator から履歴を受け取って書く。

## 書式
```
# リリース <版 / 日付>

## 利用者に見える変更
- <画面名>: <何ができるようになったか>(CS-123)
- ...

## 直した不具合
- <症状>が直りました(CS-130)

## 運用担当向け
- CMS: 新しいコンポーネント <名前> を SmartEdit で配置できます(設定手順へのリンク)
- 設定: manifest / 環境変数の変更点

## 技術メモ(開発者向け)
- 依存の更新、非推奨の削除、移行手順

## 既知の問題
- <内容>と回避策
```

## チェック
- [ ] 「利用者に見える変更」は内部の実装名(Facade、NgRx、OCC など)を使っていない
- [ ] 各項目にストーリー ID がある
- [ ] 運用担当がやるべき作業が漏れていない(CMS の配置、設定の変更)
- [ ] 既知の問題に回避策がある
